Component redesign reference

A working visual proposal for global scope and actions, the polished navigation shell, date-grouped activity, and the new transaction composer.

Light system retained No mascot Prototype only

What changes

1One app-wide control rail. Joint, Husband, and Wife remain in the same top position on every tab.
2Global actions live beside scope. Search and date filters no longer move between tab-specific layouts.
3Add becomes a labeled pill. The existing three tabs remain, with a clearer selected state.
4Transactions group by date. Rows stay flat, readable, and easy to scan without stacking extra cards.
5The composer is amount-first. Type, amount, description, pickers, keypad, and final swipe follow one vertical hierarchy.

Interaction notes

Try switching scope, opening Search or Date, pressing Add, entering an amount, changing pickers, and dragging the final control.
